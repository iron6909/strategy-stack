# 五步真实验证与二败回滚规程
1. **五步验证闭环**：禁止仅凭编译通过交差，必须执行 `Launch（启动服务/脚本）→ Doctor（检查端口与日志）→ Drive（模拟真实输入交互）→ Evidence（将截图、接口响应 JSON 或音视频抽帧保存至 .task/evidence/）→ Cleanup（杀掉测试拉起的后台进程释放 24G 内存）`。
2. **二败强制回滚**：若某次修改经验证未解决问题，立即 `git checkout` 回滚该假设的探索性改动；同一假设连续 2 次失败立即停止并退出非零状态码。
