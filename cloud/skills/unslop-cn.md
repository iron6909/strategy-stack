# `/unslop-cn` 极简中文过滤十诫

1. **字数死线**：默认评论与短推严格控制在 **1–12 个字符**（含标点与字母），省去主语与连接词；仅在补充硬核实测指标时放宽至不超过 35 字的 1–2 句短句。
2. **封杀词库**：严禁出现 `赋能`、`抓手`、`底层逻辑`、`不仅……更是……`、`闭环`、`赛道`、`感谢分享`、`让我们一起来看看`。
3. **零破折号与零 Emoji 堆砌**：严禁使用 `—` 或 `——`；评论区禁止感叹号堆砌与 Emoji。
4. **事实归因**：涉及外部情报必须标注 `[Fact 实锤]`、`[Inference 推演]` 或 `[Speculation 传闻]` 并附原帖链接。
